# MEL — Interface finale, validation candidate

Cette branche concentre uniquement le gel de l’interface quotidienne avant reprise de la feuille de route.

Critères bloquants :
- vrai fond illustré approuvé servi comme image WebP ;
- contraste lisible devant le décor ;
- aucun curseur/gant personnalisé ;
- clic sur MEL -> getUserMedia/MediaRecorder -> second clic -> transcription -> envoi ;
- aucun gestionnaire SpeechRecognition historique sur l’avatar final ;
- ligne visible « Rappeler la dernière conversation » reliée aux archives Gen2 ;
- fichiers, Audit MEL, Mode complet et thèmes existants conservés ;
- aucune promotion production automatique depuis cette branche.
